Linked Lists: Singly, Header & Two-Way Lists

Explained with playful treasure hunt analogies, visual pointer chain diagrams, insertion/deletion traces, and complete C++ implementations.

1. What is a Linked List? (The Scavenger Hunt Analogy!)

Imagine going on a Treasure Hunt: The first clue is in your pocket. It gives you a message and the address to Clue #2. Clue #2 gives you another message and the address to Clue #3. The final clue says "End of Hunt" (NULL)!

🗝️ Key Difference from Arrays

In an array, all items sit right next to each other in memory (contiguous). In a Linked List, each element (called a Node) can live anywhere in RAM! Each node holds its data and a pointer pointing to the next node in the chain.

3. Traversal & Counting Nodes

Start with a temporary pointer at head. Visit the current node, then hop to temp->next until reaching nullptr.

void traverse(Node* head) {
    Node* temp = head;
    while (temp != nullptr) {
        std::cout << temp->data << " -> ";
        temp = temp->next;
    }
    std::cout << "NULL\n";
}

int countNodes(Node* head) {
    int count = 0;
    Node* temp = head;
    while (temp != nullptr) {
        count++;
        temp = temp->next;
    }
    return count;
}

4. Insertion Operations: Head, End & Arbitrary Position

1. Insert at Beginning (O(1))

Create new node, point its next to current head, update head.

void insertBeginning(Node*& head, int val) {
    Node* newNode = new Node(val);
    newNode->next = head;
    head = newNode;
}
2. Insert at End (O(N))

Traverse to the final node (where temp->next == NULL), set its next to new node.

void insertEnd(Node*& head, int val) {
    Node* newNode = new Node(val);
    if (head == nullptr) { head = newNode; return; }
    Node* temp = head;
    while (temp->next != nullptr) temp = temp->next;
    temp->next = newNode;
}

Insert at Arbitrary Position K:

void insertAtPosition(Node*& head, int pos, int val) {
    if (pos <= 1) { insertBeginning(head, val); return; }
    Node* temp = head;
    for (int i = 1; i < pos - 1 && temp != nullptr; ++i) {
        temp = temp->next;
    }
    if (temp == nullptr) return; // Position out of bounds
    Node* newNode = new Node(val);
    newNode->next = temp->next;
    temp->next = newNode;
}

5. Deletion Operations

To delete a node, reconnect the preceding node's next pointer to bypass the target, and call delete to free memory!

void deleteHead(Node*& head) {
    if (head == nullptr) return;
    Node* temp = head;
    head = head->next; // Advance head
    delete temp;       // Free old head
}

6. Searching & Finding Min/Max

void findMinMax(Node* head, int& minVal, int& maxVal) {
    if (head == nullptr) return;
    minVal = maxVal = head->data;
    Node* temp = head->next;
    while (temp != nullptr) {
        if (temp->data < minVal) minVal = temp->data;
        if (temp->data > maxVal) maxVal = temp->data;
        temp = temp->next;
    }
}

7. Header Linked Lists (Grounded & Circular)

A Header Linked List contains a special "dummy" node at the front called the Header Node. It does not store actual user list items, but instead holds metadata (like total node count):

  • Grounded Header Linked List: The last node's next pointer points to NULL (grounded).
  • Circular Header Linked List: The last node's next pointer wraps around and points back to the Header Node! This eliminates NULL checks and allows endless circular traversal.

8. Two-Way (Doubly) Linked Lists

In a Singly Linked List, you can only move forward. In a Two-Way (Doubly) Linked List, each node has two pointers: next (to the following node) and prev (to the preceding node)!

Doubly Linked Node: `[NULL <- [prev | 10 | next] <-> [prev | 20 | next] -> NULL]`
struct DNode {
    int data;
    DNode* prev;
    DNode* next;

    DNode(int val) : data(val), prev(nullptr), next(nullptr) {}
};

void insertDoublyHead(DNode*& head, int val) {
    DNode* newNode = new DNode(val);
    if (head != nullptr) {
        newNode->next = head;
        head->prev = newNode;
    }
    head = newNode;
}

9. Memory Leak Prevention in Linked Lists

🚨 Always Free Your Nodes!

Simply setting head = nullptr; does NOT delete the nodes! They stay stranded on the heap as an invisible memory leak. You must traverse and delete each node individually:

void clearList(Node*& head) {
    Node* current = head;
    while (current != nullptr) {
        Node* nextNode = current->next;
        delete current;
        current = nextNode;
    }
    head = nullptr;
}
