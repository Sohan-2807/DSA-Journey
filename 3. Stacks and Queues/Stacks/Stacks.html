1. What is a Stack? (The Cafeteria Plates Analogy!)

Imagine a spring-loaded stack of clean plates at a cafeteria buffet:

  • When a dishwasher adds a clean plate, they place it right on TOP (called PUSH).
  • When a hungry student takes a plate, they remove the one on TOP (called POP).
  • You cannot pull a plate out from the bottom without crashing the whole stack!
📌 LIFO Principle

A Stack follows the LIFO (Last-In, First-Out) principle: the last element pushed onto the stack is the very first element popped off.

2. Array Representation of Stack (Fixed Size)

class ArrayStack {
private:
    static const int CAPACITY = 100;
    int arr[CAPACITY];
    int topIndex;

public:
    ArrayStack() : topIndex(-1) {} // -1 indicates empty stack

    bool isEmpty() const { return topIndex == -1; }
    bool isFull()  const { return topIndex == CAPACITY - 1; }

    void push(int val) {
        if (isFull()) { std::cout << "Stack Overflow!\n"; return; }
        arr[++topIndex] = val; // Pre-increment top, then insert
    }

    int pop() {
        if (isEmpty()) { std::cout << "Stack Underflow!\n"; return -1; }
        return arr[topIndex--]; // Return value, then decrement top
    }

    int peek() const {
        if (isEmpty()) return -1;
        return arr[topIndex];
    }
};

All core operations (push, pop, peek) take $O(1)$ constant time!

3. Linked List Representation (Dynamic Size)

The top of the stack is maintained at the head of the linked list. Pushing is inserting at the head ($O(1)$), and popping is deleting the head ($O(1)$). No stack overflow is possible until the entire computer RAM is exhausted!

struct StackNode {
    int data;
    StackNode* next;
    StackNode(int v) : data(v), next(nullptr) {}
};

class ListStack {
    StackNode* topNode = nullptr;
public:
    void push(int val) {
        StackNode* n = new StackNode(val);
        n->next = topNode;
        topNode = n;
    }
    int pop() {
        if (topNode == nullptr) return -1;
        StackNode* temp = topNode;
        int val = temp->data;
        topNode = topNode->next;
        delete temp;
        return val;
    }
};

4. Polish Notations (Infix, Prefix & Postfix)

Notation Operator Placement Example Parentheses Needed?
Infix (Human readable) Operator sits between operands (A + B) * C Yes (needed for precedence)
Prefix (Polish Notation) Operator sits before operands * + A B C No (unambiguous order)
Postfix (Reverse Polish) Operator sits after operands A B + C * No (ideal for compilers/calculators!)

5. Infix to Postfix Conversion Algorithm

Using an operator stack:

  1. If incoming character is an Operand (letter/number) → append directly to Output string.
  2. If incoming character is '(' → push onto Stack.
  3. If incoming character is ')' → pop operators from Stack to Output until '(' is encountered; discard both parentheses.
  4. If incoming character is an Operator → pop higher or equal precedence operators from Stack to Output, then push the new operator.
  5. At end of input, pop all remaining operators from Stack to Output.
Step-by-Step Conversion of `A + B * C`:
TokenActionStackPostfix Output
AAppend operandEmptyA
+Push operator+A
BAppend operand+A B
*Higher prec than +, push+, *A B
CAppend operand+, *A B C
EndPop all operatorsEmptyA B C * +

6. Evaluation of Postfix Expressions

Scan expression from left to right. When an operand is seen, push it onto an evaluation stack. When an operator is seen, pop two operands, apply the operator, and push the result back!

int evaluatePostfix(const std::string& exp) {
    std::stack<int> s;
    for (char ch : exp) {
        if (isdigit(ch)) {
            s.push(ch - '0'); // Push digit
        } else {
            int op2 = s.top(); s.pop();
            int op1 = s.top(); s.pop();
            switch(ch) {
                case '+': s.push(op1 + op2); break;
                case '-': s.push(op1 - op2); break;
                case '*': s.push(op1 * op2); break;
                case '/': s.push(op1 / op2); break;
            }
        }
    }
    return s.top();
}

7. Classic Applications of Stacks

  • Function Call Stack: Tracking return addresses and local stack frames during function execution & recursion.
  • Parentheses Balancing: Verifying balanced brackets in code syntax checkers (e.g., {[()]}).
  • Undo/Redo Mechanism: Text editors pushing user actions onto an undo stack.
  • Browser History Navigation: Back button pops previously visited URLs from the history stack.
