1. What is a Data Structure? (Like Teaching a Kid!)

Imagine your bedroom has toys scattered everywhere. If you throw them randomly into a pile, finding your favorite Lego block takes forever! But if you organize them into labeled drawers or transparent boxes, you can grab any toy in 1 second.

🧸 Definition

A Data Structure is simply a specialized way of organizing, storing, and managing data in a computer's memory so that we can perform operations (search, insert, delete, sort) quickly and efficiently.

2. Asymptotic Notations: Big-O ($O$), Omega ($\Omega$), Theta ($\Theta$)

How do computer scientists measure if an algorithm is fast or slow? We don't use a stopwatch (because a fast supercomputer runs code faster than an old laptop). Instead, we count how the number of basic operations grows as the input size $N$ gets larger.

1. Big-O ($O$) — Worst Case (Upper Bound)

The "It won't get worse than this" Guarantee: Maximum time an algorithm will take for any input of size $N$.

Example: Linear search worst case is $O(N)$ (target is at the very last index or absent).

2. Big-Omega ($\Omega$) — Best Case (Lower Bound)

The "Best Possible Luck" Bound: Minimum time an algorithm takes under the most ideal input scenario.

Example: Linear search best case is $\Omega(1)$ (target is found on the very first try at index 0).

3. Big-Theta ($\Theta$) — Average / Tight Bound

The "Exact Tight Growth Rate": When the algorithm's upper bound and lower bound grow at the exact same rate ($c_1 g(n) \le f(n) \le c_2 g(n)$).

3. Time-Space Trade-off

In computer science, you often have to choose between saving time (execution speed) or saving space (memory consumption):

  • Save Space, Spend Time: Compress data to use tiny RAM, but spend CPU time decompressing it repeatedly.
  • Save Time, Spend Space: Precompute and store lookup tables in memory (like a Hash Table or lookup cache) so retrieval takes instant $O(1)$ time, but consumes extra RAM.

5. Array Insertion: The Step-by-Step Shifting Process

Imagine people standing in a straight queue. If someone wants to cut in at position 2, everyone from position 2 to the end must take one step back to create an empty chair!

Visualizing Insertion of `99` at Index `2`:

1. Original Array: [10, 20, 30, 40] (Size = 4)

2. Shift elements right starting from the end: 40 moves to index 4, 30 moves to index 3.

3. Gap opened at index 2: [10, 20, __, 30, 40]

4. Place 99 into index 2: [10, 20, 99, 30, 40] (Size = 5)

bool insertAt(int arr[], int& size, int capacity, int index, int element) {
    if (size >= capacity || index < 0 || index > size) return false;

    // Shift elements right from back to front:
    for (int i = size; i > index; --i) {
        arr[i] = arr[i - 1];
    }
    arr[index] = element; // Insert element
    size++;               // Increase size
    return true;
}

Complexity: Worst Case $O(N)$ (inserting at index 0 requires shifting all $N$ elements).

6. Array Deletion: Step-by-Step Left Shift

When someone leaves the line, everyone behind them takes one step forward to close the hole!

bool deleteAt(int arr[], int& size, int index) {
    if (index < 0 || index >= size) return false;

    // Shift elements left:
    for (int i = index; i < size - 1; ++i) {
        arr[i] = arr[i + 1];
    }
    size--; // Decrease size
    return true;
}

Complexity: Worst Case $O(N)$ (deleting index 0 shifts $N - 1$ elements).

7. Merging Two Sorted Arrays

Compare the current front elements of both arrays and pick the smaller one to place into the merged array.

void mergeSorted(const int A[], int m, const int B[], int n, int C[]) {
    int i = 0, j = 0, k = 0;
    while (i < m && j < n) {
        if (A[i] <= B[j]) C[k++] = A[i++];
        else              C[k++] = B[j++];
    }
    // Copy remaining elements:
    while (i < m) C[k++] = A[i++];
    while (j < n) C[k++] = B[j++];
}

Complexity: $O(m + n)$ time and $O(m + n)$ space.
