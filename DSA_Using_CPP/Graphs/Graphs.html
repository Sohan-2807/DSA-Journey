Graphs, Traversals & Shortest Path Algorithms

Explained with city road-network analogies, BFS ripple waves, DFS maze explorers, relaxation tables, and production-ready C++ code.

1. What is a Graph? (The Flight & Cities Map Analogy!)

Imagine a map of the world:

  • Cities are called Vertices (Nodes).
  • Flight routes between cities are called Edges (Links).
  • Flight ticket prices are the Weights on those edges!

A Graph $G = (V, E)$ consists of a set of vertices $V$ and edges $E$.

2. Graph Representations: Matrix vs List

1. Adjacency Matrix (2D Array)

A $V \times V$ grid where matrix[u][v] = 1 (or edge weight) if an edge connects $u$ and $v$.

Space: $O(V^2)$ (Heavy, best for dense graphs where $E \approx V^2$).

2. Adjacency List (Vector of Vectors)

Each vertex stores a list of its direct neighbors only:

std::vector<std::vector<int>> adj(V);

Space: $O(V + E)$ (Optimal, standard choice for most problems!).

3. Breadth-First Search (BFS): "The Water Ripple"

The Strategy: Drop a pebble into water; ripples expand outwards layer by layer. BFS visits the starting node, then all its immediate neighbors (distance 1), then all their neighbors (distance 2), and so on! Uses a Queue and a visited[] boolean array.

void bfs(int start, const std::vector<std::vector<int>>& adj, int V) {
    std::vector<bool> visited(V, false);
    std::queue<int> q;

    visited[start] = true;
    q.push(start);

    while (!q.empty()) {
        int u = q.front(); q.pop();
        std::cout << u << " ";

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
}

Complexity: Time $O(V + E)$ | Space $O(V)$.

4. Depth-First Search (DFS): "The Maze Explorer"

The Strategy: Imagine walking through a dark labyrinth: pick a path and walk as far forward as possible until hitting a dead end. Then backtrack to the nearest fork in the road and try the next branch! Uses Recursion / System Call Stack.

void dfsHelper(int u, const std::vector<std::vector<int>>& adj, std::vector<bool>& visited) {
    visited[u] = true;
    std::cout << u << " ";

    for (int v : adj[u]) {
        if (!visited[v]) dfsHelper(v, adj, visited);
    }
}

Complexity: Time $O(V + E)$ | Space $O(V)$.

5. Dijkstra's Algorithm (Single Source Shortest Path)

Finds the shortest distance from a single starting vertex to all other vertices in a weighted graph with non-negative edge weights. Uses a Greedy approach with a Min-Priority Queue.

📌 Edge Relaxation Condition
if (dist[u] + weight(u, v) < dist[v]) → dist[v] = dist[u] + weight(u, v)

Complexity: $O((V + E) \log V)$ using a binary min-heap priority queue.

6. Bellman-Ford Algorithm (Handles Negative Edges)

Why do we need Bellman-Ford if Dijkstra is faster? Because Dijkstra fails when edges have negative weights (like getting a discount or rebate on a travel segment)!

  • Relaxes all $E$ edges $V - 1$ times.
  • Negative Cycle Detection: If doing a $V$-th relaxation still reduces any distance, a negative cycle exists (meaning you can loop infinitely to get negative infinite cost!).

Complexity: Time $O(V \times E)$ | Space $O(V)$.

7. Floyd-Warshall Algorithm (All-Pairs Shortest Path)

Computes the shortest path between every single pair of vertices $(u, v)$ simultaneously using Dynamic Programming:

📌 Dynamic Programming Recurrence
dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) 
for (int k = 0; k < V; ++k)
    for (int i = 0; i < V; ++i)
        for (int j = 0; j < V; ++j)
            if (dist[i][k] + dist[k][j] < dist[i][j])
                dist[i][j] = dist[i][k] + dist[k][j];

Complexity: Time $\Theta(V^3)$ | Space $O(V^2)$.
