1. What is a Heap? (The Corporate Ladder Analogy!)

A Binary Heap is a Complete Binary Tree that satisfies the Heap Property:

  • Max-Heap: Every parent node is strictly greater than or equal to its children. The CEO (maximum element) always sits at the very root!
  • Min-Heap: Every parent node is strictly less than or equal to its children. The root holds the minimum element.

Because a heap is always a Complete Binary Tree, it is stored in a clean, compact 1D array without pointers!

2. Heap Operations: Insertion & Deletion

  • Insertion ($O(\log N)$): Insert new element at the very end of the array, then bubble it up (Up-Heapify / Shift-Up) until heap order is restored.
  • Deletion ($O(\log N)$): Always remove the root element. Replace root with the last element in the array, then push it down (Down-Heapify / Shift-Down).
void heapify(int arr[], int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;

    if (largest != i) {
        std::swap(arr[i], arr[largest]);
        heapify(arr, n, largest); // Recursively heapify affected subtree
    }
}

3. HeapSort ($O(N \log N)$ In-Place)

1. Build a Max-Heap from the input array ($O(N)$ time).

2. Swap the root (largest) with the last element, reduce heap size by 1, and call heapify on the root. Repeat until sorted!

void heapSort(int arr[], int n) {
    // Build max heap:
    for (int i = n / 2 - 1; i >= 0; --i) heapify(arr, n, i);

    // Extract elements one by one from heap:
    for (int i = n - 1; i > 0; --i) {
        std::swap(arr[0], arr[i]); // Move current root to end
        heapify(arr, i, 0);        // Call max heapify on reduced heap
    }
}

4. Hashing Fundamentals & Hash Tables

The Coat Check Analogy: When you check your winter coat at a theater, they hand you a numbered plastic token (a Hash). When you leave, they instantly hand your coat back without searching through every coat in the cloakroom! Hashing achieves average $O(1)$ constant time lookup.

📌 Division Hash Function
h(k) = k mod m (where $m$ is the table size, ideally a prime number).

Collision: When two different keys produce the exact same bucket index ($h(k_1) = h(k_2)$).

5. Open Hashing (Separate Chaining)

Each slot in the hash table points to the head of a linked list. If multiple keys hash to the same bucket, they simply get chained to that bucket's list!

class ChainedHashTable {
    int BUCKETS = 7;
    std::vector<std::list<int>> table;
public:
    ChainedHashTable() : table(BUCKETS) {}

    int hashFunc(int key) { return key % BUCKETS; }

    void insert(int key) {
        table[hashFunc(key)].push_back(key);
    }
};

6. Closed Hashing (Open Addressing)

All elements live directly inside the table array (no linked lists). If a collision occurs at index $h$, we probe to find the next available empty slot inside the table.

7. Probing Techniques Comparison

1. Linear Probing

Probe sequence: check $h, h+1, h+2, \dots \bmod m$.

Drawback: Causes Primary Clustering (long continuous blocks of occupied cells form, slowing searches down).

2. Quadratic Probing

Probe sequence: $h(k, i) = (h'(k) + c_1 i + c_2 i^2) \bmod m$.

Jumps further to eliminate primary clustering, but can cause Secondary Clustering.

3. Double Hashing (Best)

Uses a secondary hash function to calculate step size:

h(k, i) = (h1(k) + i * h2(k)) mod m

Benefit: Completely eliminates both primary and secondary clustering!
