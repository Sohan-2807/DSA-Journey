Queues: Linear, Circular, Priority & Deques

Explained with movie ticket line analogies, circular clock face visualizations, modulo arithmetic proofs, and complete C++ implementations.

1. What is a Queue? (The Movie Ticket Counter Analogy!)

Imagine people lining up at a movie theater ticket counter:

  • The first person to join the line gets their ticket first and leaves first (FIFO: First-In, First-Out).
  • New people join at the REAR (called ENQUEUE).
  • People leave from the FRONT (called DEQUEUE).
  • No cutting in line allowed!
Visualizing Queue Flow:
← DEQUEUE (FRONT)
Alice
Bob
Charlie
← ENQUEUE (REAR)

2. Linear Queue (Array Based)

Using two index variables: front and rear.

class LinearQueue {
    static const int MAX = 5;
    int arr[MAX];
    int front = -1, rear = -1;

public:
    bool isEmpty() const { return front == -1 || front > rear; }
    bool isFull()  const { return rear == MAX - 1; }

    void enqueue(int val) {
        if (isFull()) { std::cout << "Queue Overflow!\n"; return; }
        if (front == -1) front = 0;
        arr[++rear] = val;
    }

    int dequeue() {
        if (isEmpty()) { std::cout << "Queue Underflow!\n"; return -1; }
        return arr[front++];
    }
};
⚠️ The Limitation: False Overflow

If you enqueue 5 items and dequeue 5 items, rear is at the end of the array (MAX - 1). Even though the array is completely empty, isFull() returns true! Memory in front is wasted.

3. Circular Queue (The Clock Face Solution!)

Instead of a straight line, imagine the queue as a circle like a clock face. When rear reaches the end of the array, it wraps back around to index 0 using the modulo operator (%)!

📌 Modulo Advancement Formula
rear = (rear + 1) % CAPACITY  |  front = (front + 1) % CAPACITY 
class CircularQueue {
    static const int SIZE = 5;
    int arr[SIZE];
    int front = -1, rear = -1;

public:
    bool isEmpty() const { return front == -1; }
    bool isFull()  const { return (rear + 1) % SIZE == front; }

    void enqueue(int val) {
        if (isFull()) { std::cout << "Circular Queue Full!\n"; return; }
        if (front == -1) front = 0;
        rear = (rear + 1) % SIZE;
        arr[rear] = val;
    }

    int dequeue() {
        if (isEmpty()) { std::cout << "Circular Queue Empty!\n"; return -1; }
        int val = arr[front];
        if (front == rear) { front = rear = -1; } // Reset when last item removed
        else               { front = (front + 1) % SIZE; }
        return val;
    }
};

4. Linked List Representation of Queue

Enqueue at rear ($O(1)$) and dequeue from front ($O(1)$). No size limits!

5. Priority Queues: "The Hospital Emergency Room"

In a standard queue, you are served purely in order of arrival. In a Priority Queue, an element with higher priority is served before an element with lower priority, regardless of who arrived first (just like an emergency room treating critical patients first)!

  • Ascending Priority Queue: Smallest value has the highest priority.
  • Descending Priority Queue: Largest value has the highest priority.
  • Implementation: Typically implemented using a Heap for efficient $O(\log N)$ enqueue and dequeue.

6. Double Ended Queue (Deque)

A generalized queue where insertion and deletion can occur at both ends (both Front and Rear):

  • push_front() / pop_front()
  • push_back() / pop_back()

Variations:

  • Input-Restricted Deque: Insertion allowed at one end only, deletion allowed at both ends.
  • Output-Restricted Deque: Deletion allowed at one end only, insertion allowed at both ends.

7. Real-World Applications of Queues

  • Operating System Scheduling: CPU Round-Robin process scheduling, Ready Queue.
  • Hardware Buffers: Keyboard keystroke buffer, printer spooling.
  • Graph Algorithms: Breadth-First Search (BFS) traversal.
