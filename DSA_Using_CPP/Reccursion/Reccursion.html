1. What is Recursion? (The Russian Matryoshka Doll!)

Imagine opening a wooden Russian doll: inside is a smaller doll, inside that is an even smaller doll, until you reach the tiniest, solid doll that cannot be opened (the BASE CASE)!

📌 The Two Mandatory Rules of Recursion
  1. Base Case: The stopping condition that prevents infinite looping.
  2. Recursive Step: Calling the function with a strictly smaller sub-problem that moves closer to the base case.

2. Factorial, Fibonacci & Euclid's GCD

1. Factorial ($N! = N \times (N-1)!$)
int fact(int n) {
    if (n <= 1) return 1; // Base Case
    return n * fact(n - 1);
}
2. Euclid's GCD ($\gcd(a, b) = \gcd(b, a \% b)$)
int gcd(int a, int b) {
    if (b == 0) return a; // Base Case
    return gcd(b, a % b);
}

3. Towers of Hanoi (The Legendary Puzzle!)

The Story: You have 3 pegs: Source (A), Auxiliary (B), and Destination (C). Move $N$ disks from Source to Destination following two rules:

  1. Move only one disk at a time.
  2. Never place a larger disk on top of a smaller disk!
The Strategy for N Disks:

1. Move top $N-1$ disks from Source → Auxiliary (using Destination as temporary).

2. Move the largest $N$-th disk directly from Source → Destination.

3. Move the $N-1$ disks from Auxiliary → Destination (using Source as temporary).

void towersOfHanoi(int n, char src, char aux, char dst) {
    if (n == 1) {
        std::cout << "Move disk 1 from " << src << " -> " << dst << '\n';
        return;
    }
    towersOfHanoi(n - 1, src, dst, aux);
    std::cout << "Move disk " << n << " from " << src << " -> " << dst << '\n';
    towersOfHanoi(n - 1, aux, src, dst);
}
📌 Total Moves Formula

Total moves required for $N$ disks: $T(N) = 2^N - 1$. Time Complexity: $O(2^N)$.

4. Divide and Conquer Strategy

Break a huge, hard problem into smaller, bite-sized identical sub-problems (Divide), solve each recursively (Conquer), and merge the solutions together (Combine).

5. Merge Sort ($O(N \log N)$ Guaranteed)

Divide the array into two equal halves until each sub-array has only 1 element (a single element is already sorted!). Then merge the sorted halves back together.

void merge(int arr[], int l, int m, int r) {
    int n1 = m - l + 1, n2 = r - m;
    std::vector<int> L(n1), R(n2);
    for (int i = 0; i < n1; ++i) L[i] = arr[l + i];
    for (int j = 0; j < n2; ++j) R[j] = arr[m + 1 + j];

    int i = 0, j = 0, k = l;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) arr[k++] = L[i++];
        else              arr[k++] = R[j++];
    }
    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}

void mergeSort(int arr[], int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(arr, l, m);
    mergeSort(arr, m + 1, r);
    merge(arr, l, m, r);
}

Complexity: Always $O(N \log N)$ in all cases! Space: $O(N)$ auxiliary.

6. Quick Sort

Pick one element as a Pivot. Partition the array so all numbers smaller than the pivot are on the left, and all numbers greater are on the right. Then recursively sort both sides!

int partition(int arr[], int low, int high) {
    int pivot = arr[high]; // Pick rightmost as pivot
    int i = low - 1;

    for (int j = low; j < high; ++j) {
        if (arr[j] < pivot) {
            i++;
            std::swap(arr[i], arr[j]);
        }
    }
    std::swap(arr[i + 1], arr[high]);
    return i + 1; // Final pivot index
}

void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}
