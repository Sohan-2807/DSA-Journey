1. What is a Tree? (The Family Tree Analogy!)

In computer science, a Tree is an upside-down tree: the Root sits at the very top, and branches grow downwards towards the leaves!

  • Root: The topmost node with no parent.
  • Leaf Node: A node with zero children.
  • Binary Tree: A hierarchical data structure where every node has at most 2 children (called Left Child and Right Child).
Visual ASCII Binary Tree:
        [ 50 ]  <-- Root Node
        /    \
     [ 30 ]  [ 70 ]
     /    \      \
   [20]  [40]   [80] <-- Leaf Nodes

2. Types of Binary Trees (Syllabus Core)

1. Complete Binary Tree

Every level is completely filled, except possibly the last level, which is filled from left to right without gaps. (Critical for Heaps!).

2. Extended / Strict Binary Tree

Every node has either 0 or exactly 2 children. No node has only 1 child.

3. Full Binary Tree

All nodes have 2 children, and all leaf nodes sit at the exact same depth level.

3. Memory Representations of Trees

A. Linked Representation (Pointers)
struct TreeNode {
    int data;
    TreeNode* left;
    TreeNode* right;

    TreeNode(int v) : data(v), left(nullptr), right(nullptr) {}
};
B. Sequential (Array) Representation

Stored in a 1D array using mathematical parent-child indexing (1-based index):

  • Parent at index $i$:
  • Left Child: $2 \times i$
  • Right Child: $2 \times i + 1$
  • Parent of node $j$: $\lfloor j / 2 \rfloor$

4. Binary Search Tree (BST)

📌 The Golden Rule of BST

For every single node: All values in the Left subtree must be LESS than the node, and all values in the Right subtree must be GREATER than the node!

Left_Subtree < Node < Right_Subtree

5. BST Operations: Search, Insert & Delete

1. Searching in BST ($O(h)$ time)

TreeNode* searchBST(TreeNode* root, int key) {
    if (root == nullptr || root->data == key) return root;
    if (key < root->data) return searchBST(root->left, key);
    return searchBST(root->right, key);
}

2. Insertion in BST

TreeNode* insertBST(TreeNode* root, int val) {
    if (root == nullptr) return new TreeNode(val);
    if (val < root->data) root->left = insertBST(root->left, val);
    else if (val > root->data) root->right = insertBST(root->right, val);
    return root;
}

3. Deletion in BST (The 3 Cases)

  • Case 1 (Leaf Node): Has 0 children → simply delete the node and set parent pointer to NULL.
  • Case 2 (One Child): Node has only 1 child → bypass the node and connect parent directly to that child.
  • Case 3 (Two Children): Find the In-Order Successor (smallest value in the Right subtree), copy its value to the current node, then recursively delete that successor!

6. Tree Traversals (In-order, Pre-order, Post-order)

TraversalOrder of VisitSpecial Property in BST
In-Order Left → Root → Right Always prints BST values in sorted ascending order!
Pre-Order Root → Left → Right Used to clone/serialize a tree copy.
Post-Order Left → Right → Root Used to delete trees from bottom to top (freeing memory). 
void inOrder(TreeNode* root) {
    if (root == nullptr) return;
    inOrder(root->left);
    std::cout << root->data << " ";
    inOrder(root->right);
}
