1. What is Searching? (Child's Analogy)

Imagine you have a deck of animal flashcards. Searching is simply looking through the deck until you find the Lion card, or confirming that the lion is not in the deck!

2. Linear Search

The "One-by-One" Approach: Start at the first card. Is it a Lion? No → check next. Is it a Lion? No → check next... repeat until found or end of cards.

int linearSearch(const int arr[], int n, int target) {
    for (int i = 0; i < n; ++i) {
        if (arr[i] == target) return i; // Found at index i
    }
    return -1; // Target absent
}

Best Case: $\Omega(1)$ (found at index 0) | Worst Case: $O(N)$ (at the end or absent).

3. Sentinel Linear Search

In standard linear search, the loop checks two conditions on every iteration: i < n and arr[i] == target. Sentinel search places the target at the very end of the array, removing the i < n bounds check inside the loop to run slightly faster!

int sentinelSearch(int arr[], int n, int target) {
    int last = arr[n - 1];
    arr[n - 1] = target; // Set sentinel
    int i = 0;
    while (arr[i] != target) i++;
    arr[n - 1] = last;   // Restore original

    if (i < n - 1 || arr[n - 1] == target) return i;
    return -1;
}

4. Binary Search: The Divide & Conquer Game

The "Higher or Lower" Guessing Game: Imagine someone picks a secret number between 1 and 100. If you guess 50 and they say "Higher!", you instantly throw away all numbers from 1 to 50! You just cut the problem in half with one question!

⚠️ Prerequisite

Binary Search strictly requires the array to be sorted!

Visual Step: Target = 70 in `[10, 20, 30, 40, 50, 60, 70, 80, 90]`

1. Middle is 50 (Index 4). Target 70 > 50 → Eliminate left half: [10..50] gone!

2. Search in right half: [60, 70, 80, 90]. New Middle is 70 (Index 6) → MATCH FOUND!

int binarySearch(const int arr[], int n, int target) {
    int low = 0, high = n - 1;
    while (low <= high) {
        // Safe midpoint avoiding integer overflow:
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)      return mid;
        else if (arr[mid] < target) low = mid + 1; // Search right
        else                        high = mid - 1; // Search left
    }
    return -1;
}

Time Complexity: $O(\log_2 N)$. Even with 1,000,000,000 items, Binary Search finds the answer in at most 30 comparisons!

5. First and Last Occurrences in a Sorted Array

When duplicate elements exist, standard binary search may stop at any instance. To find the first or last index, don't stop upon finding a match—keep searching left or right!

int findFirstOccurrence(const int arr[], int n, int target) {
    int low = 0, high = n - 1, result = -1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == target) {
            result = mid;
            high = mid - 1; // Keep searching LEFT for earlier occurrence!
        } else if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return result;
}

6. Interpolation Search: The Human Dictionary Strategy

When searching for "Zebra" in a physical dictionary, you don't open the exact middle (M). You flip directly towards the end! Interpolation Search uses mathematical linear interpolation to estimate the position:

📌 Probe Position Formula
pos = low + [ (target - arr[low]) * (high - low) / (arr[high] - arr[low]) ]

Complexity: $O(\log(\log N))$ for uniformly distributed sorted data, but degrades to $O(N)$ for skewed data.
