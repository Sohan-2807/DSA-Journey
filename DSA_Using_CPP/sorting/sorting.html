1. What is Sorting? (Child's Analogy)

Imagine lining up students in school from shortest to tallest. Sorting is arranging a collection of items in a specific order (ascending or descending).

2. Bubble Sort: The "Air Bubbles in Water" Method

The Idea: Just like heavy rocks sink to the bottom while light air bubbles float to the top, Bubble Sort compares adjacent pairs of numbers. If the left number is bigger than the right, they swap! In each full pass, the largest unsorted number bubbles up to its final rightmost position.

Visualizing 1st Pass on `[5, 1, 4, 2, 8]`:

Compare (5, 1) → Swap: [1, 5, 4, 2, 8]

Compare (5, 4) → Swap: [1, 4, 5, 2, 8]

Compare (5, 2) → Swap: [1, 4, 2, 5, 8]

Compare (5, 8) → No swap. 8 is now locked in its final spot at the end!

void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        bool swapped = false; // Optimization flag
        for (int j = 0; j < n - i - 1; ++j) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break; // Array already sorted! O(N) best case!
    }
}

Best Case: $O(N)$ (already sorted with flag) | Worst/Avg Case: $O(N^2)$ | Space: $O(1)$ | Stable: Yes.

3. Selection Sort: "Finding the Shortest Kid"

The Idea: Look across the entire unsorted group, find the absolute smallest element, and swap it into the very front position (index 0). Then find the next smallest from the remaining kids and place it at index 1, and so on!

Visualizing Passes on `[64, 25, 12, 22, 11]`:

Pass 1: Smallest is 11. Swap with 64 → [11 | 25, 12, 22, 64]

Pass 2: Smallest remaining is 12. Swap with 25 → [11, 12 | 25, 22, 64]

Pass 3: Smallest remaining is 22. Swap with 25 → [11, 12, 22 | 25, 64]

Pass 4: Smallest remaining is 25. Already in place! Array sorted!

void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        int minIdx = i;
        for (int j = i + 1; j < n; ++j) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        if (minIdx != i) std::swap(arr[i], arr[minIdx]);
    }
}

Key Trait: Performs at most $O(N)$ swaps (great when memory write operations are very expensive!). Time: Always $\Theta(N^2)$ | Stable: No.

4. Insertion Sort: "Sorting a Hand of Playing Cards"

The Idea: When holding playing cards in your hand, you pick up one card at a time from the table and insert it into its correct position among the cards already sorted in your hand by shifting larger cards to the right.

Visualizing Hand of Cards on `[12, 11, 13, 5, 6]`:

Card 1 (11): Less than 12 → shift 12 right, drop 11 → [11, 12 | 13, 5, 6]

Card 2 (13): Greater than 12 → stays put → [11, 12, 13 | 5, 6]

Card 3 (5): Shift 13, 12, 11 right → drop 5 → [5, 11, 12, 13 | 6]

Card 4 (6): Shift 13, 12, 11 right → drop 6 → [5, 6, 11, 12, 13]

void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; ++i) {
        int key = arr[i];
        int j = i - 1;

        // Shift elements of arr[0..i-1] that are greater than key to right:
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key; // Drop into correct position
    }
}
💡 Why Insertion Sort is Excellent in Practice

For small arrays (e.g., $N \le 16$) or arrays that are nearly sorted, Insertion Sort runs in lightning-fast $O(N)$ time with almost zero overhead. It is used inside standard hybrid sorts like Introsort and Timsort!

5. Stability & In-Place Concepts

  • In-Place Sorting: An algorithm that sorts the input array without allocating extra auxiliary memory (uses $O(1)$ additional space). Bubble, Selection, and Insertion sorts are all In-Place.
  • Stable Sorting: Preserves the relative order of duplicate elements. If card $5_\spadesuit$ appeared before $5_\heartsuit$ in the input, a stable sort guarantees $5_\spadesuit$ remains before $5_\heartsuit$.
    • Stable: Bubble Sort, Insertion Sort, Merge Sort.
    • Unstable: Selection Sort, Quick Sort, Heap Sort.
