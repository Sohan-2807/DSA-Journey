# ⚡ DSA Journey

My personal repository for learning and practicing Data Structures and Algorithms from the ground up.

## 📂 Structure

```text
DSA-Journey/
├── 1. Introduction, Arrays, Searching and Sorting
├── 2. Linked Lists
├── 3. Stacks and Queues
├── 4. Recursion and Trees
├── 5. Heaps and Hashing
└── 6. Graphs
```

## Overview

- **Unit 1 — Arrays, Searching & Sorting:** Complexity analysis, array operations, linear/binary search, bubble, insertion, and selection sort.
- **Unit 2 — Linked Lists:** Singly, doubly, circular, and header linked lists with insertion, deletion, and traversal.
- **Unit 3 — Stacks & Queues:** Array/list representations, infix-to-postfix expressions, circular queues, priority queues, and deques.
- **Unit 4 — Recursion & Trees:** Recursion fundamentals, binary tree traversals (Pre, In, Post), and Binary Search Tree (BST) operations.
- **Unit 5 — Heaps & Hashing:** Min/Max heaps, HeapSort, hash tables, and collision handling (chaining & open addressing).
- **Unit 6 — Graphs:** Adjacency matrix/list representations, BFS, DFS, and shortest path algorithms (Dijkstra, Bellman-Ford, Floyd-Warshall).

## 🎯 Goal

Build strong problem-solving fundamentals in Data Structures and Algorithms for competitive programming and technical interviews.

## 📈 Progress

Continuously updated with working implementations, practice problems, and algorithm solutions as I learn.
