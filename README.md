## 🎯 Syllabus Concepts Covered

### Unit I: Introduction, Arrays, Searching and Sorting
* **Introduction**: Basic concepts and notations, Complexity analysis: time-space trade-off, Omega (\(\Omega\)) notation, Theta (\(\Theta\)) notation, Big O (\(O\)) notation, Basic data structures.
* **Arrays**: Linear arrays: memory representation, Array operations: traversal, insertion (beginning, position, end), deletion, sorting, searching, merging, and their complexity analysis.
* **Sorting & Searching**: Bubble sort, Insertion sort, Selection sort, Linear search, Binary search, Interpolation search, Sentinel search.

### Unit II: Linked Lists
* **Introduction & Representation**: Memory representation, dynamic node allocation, pointer manipulation.
* **Operations**: Traversal, searching, insertion (beginning, position, end), deletion (beginning, position, end), finding min/max values.
* **Variants**:
  * **Header Linked Lists**: Grounded header linked list and circular header linked list.
  * **Two-way Lists (Doubly Linked Lists)**: Insertion, deletion, searching, bidirectional traversal.
  * **Circular Linked Lists**: Circular singly linked list insertion, deletion, and traversal.

### Unit III: Stacks and Queues
* **Stacks**: List and array representations, Stack operations (push, pop, peek, traversal, isEmpty, isFull), Stack overflow/underflow.
* **Arithmetic Expressions**: Polish notation (prefix), Infix, Postfix (reverse Polish), Expression evaluation and transformations (Infix-to-Postfix, Infix-to-Prefix, Postfix evaluation).
* **Queues**: Array and linked list representation, operations (traversal, insertion/enqueue, deletion/dequeue).
* **Advanced Queues**: Circular queues, Priority queues, Double-Ended Queues (Deques).

### Unit IV: Recursion and Trees
* **Recursion**: Recursion principles, call stack execution, recurrence relations, Towers of Hanoi, Recursive sorting (Merge Sort, Quick Sort).
* **Binary Trees**: Introduction, Complete and extended binary trees, Memory representation (sequential and linked).
* **Tree Traversals**: Recursive and iterative (stack-based) Pre-order, In-order, and Post-order traversals.
* **Binary Search Tree (BST)**: Introduction, searching, insertion, and deletion operations (leaf, single child, two children with inorder successor).

### Unit V: Heaps and Hashing
* **Heaps**: Heap definition (Min-Heap, Max-Heap), Heap operations (insertion, deletion), HeapSort and complexity.
* **Hashing**: Hash functions, Hash tables, Collision resolution techniques.
* **Open Hashing**: Separate chaining.
* **Closed Hashing (Open Addressing)**: Linear probing, Quadratic probing, Double hashing.

### Unit VI: Graphs
* **Graph Fundamentals**: Graph representations (Adjacency Matrix, Adjacency List), Directed and Undirected graphs.
* **Graph Traversals**: Breadth-First Search (BFS), Depth-First Search (DFS).
* **Shortest Path Algorithms**: Dijkstra’s Algorithm, Bellman-Ford Algorithm, Floyd-Warshall Algorithm.
